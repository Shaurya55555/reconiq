# Sample batch (seed=5, 100 orders)

Static snapshot generated by `backend/scripts/export_sample_batch.py`, so a
reviewer can inspect real input/output data without running anything.
Regenerate anytime with the same script — it's deterministic given the seed.

- `orders.csv`, `settlements.csv`, `bank_lines.csv` — the three input sources
- `matches.csv`, `exceptions.csv`, `audit_trail.csv` — the matcher's output
- `summary.json` — match rate, ground-truth accuracy, throughput
