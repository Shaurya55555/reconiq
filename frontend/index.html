Transaction-count accuracy treats every order equally; value-weighted accuracy weights order-level correctness by rupee amount instead (it measures decision correctness, not that money was physically verified moving). False-clear = confidently wrong (matched when it should have been an exception, the dangerous failure). Safe-miss = conservative (flagged as an exception when it should have matched, money just sits reviewable instead of moving wrong).
